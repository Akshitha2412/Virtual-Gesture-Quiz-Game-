# Virtual-Gesture-Quiz-Game-
This application allows users to participate in a quiz without using a keyboard or mouse. Instead, answers can be selected using hand gestures detected through a webcam. The system tracks finger movements and allows users to interact with virtual answer buttons displayed on the screen.


### Key Features:
 • Real-time hand gesture recognition
 • Touch-free selection of quiz options
 • Interactive quiz interface with a progress indicator
 • Automatic calculation and display of the final score
### Technologies Used:
 • Python
 • OpenCV
 • CVZone (MediaPipe Hand Tracking)
This project highlights how computer vision technology can improve human–computer interaction by enabling touchless and interactive systems.
